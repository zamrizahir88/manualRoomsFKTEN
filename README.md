# Manual Pengguna – Sistem Tempahan Bilik FKTEN

Interactive user manual (slides, Bahasa Melayu) for the room and lab booking system of the Fakulti Kejuruteraan & Teknologi Elektronik (FKTEN), Universiti Malaysia Perlis.

- `index.html` – the slide manual. Arrow keys / swipe to move, **O** for contents, **F** for full screen.
- `assets/shots/` – screenshots taken from the system's mock with **made-up names and phone numbers** (no real staff data).

No build step: open `index.html` in a browser or view it on GitHub Pages.

Screenshots are regenerated with `node capture/manual-shots.mjs` in the system's `docs/video` folder (needs the mock served on port 5800).
